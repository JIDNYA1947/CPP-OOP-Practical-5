# CPP-OOP-Practical-5

## Aim
To implement class and objects, `this` pointer, inline function, static member function, and friend class in C++.

## Program – Bank Account

**File:** `Code.cpp`

This program demonstrates:

- Class and objects
- Constructor
- `this` pointer
- Inline function
- Static member variable
- Static member function
- Friend class
- Accessing private data using a friend class

## Concepts Used

- Classes and objects
- Constructor
- `this` pointer
- Inline function
- Static member variable and function
- Friend class
- Private data members
- Object creation and member function calls
